# System Diagrams

This directory contains various diagrams that document the College Complaint Management System's architecture and workflows.

## Available Diagrams

1. [Entity Relationship Diagram](1_entity_relationship.md)
   - Shows relationships between all models
   - Illustrates data flow
   - Defines cardinality

2. [Class Diagram](2_class_diagram.md)
   - Details model attributes
   - Shows methods
   - Defines data types

3. [Workflow Diagram](3_workflow_diagram.md)
   - Illustrates complaint process
   - Shows state transitions
   - Defines actions and triggers

4. [Database Schema](4_database_schema.md)
   - Shows indexes
   - Lists constraints
   - Defines validations

## How to View

These diagrams are written in Mermaid markdown syntax. To view them:

1. Use GitHub's built-in Mermaid renderer
2. Use VS Code with Mermaid extension
3. Use online Mermaid Live Editor
4. Use any Markdown viewer that supports Mermaid

## Updating Diagrams

When making changes to the system:
1. Update relevant diagrams
2. Keep documentation in sync with code
3. Add new diagrams as needed
4. Maintain consistency across diagrams
